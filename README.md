# ByteSpace Auth (Login + Register)

React 18 + Vite + TypeScript + Tailwind v4 + React Router.

```bash
npm install
npm run dev      # http://localhost:5173/login  and /register
```

1. Export the assets listed in `ASSETS.md` into `src/assets/`.
2. Open `/login` and `/register` next to the Figma frames (1440x1024) and compare.
3. Design tokens live in `src/index.css` under `@theme`.
